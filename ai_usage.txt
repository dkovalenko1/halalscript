2. WHAT THE AI PRODUCED
-----------------------

- DESIGN.md: first a draft that offered several spellings for each keyword
  (with emoji aliases, ornate brackets, and other options), then the final
  version after my decisions in prompt 2. It holds the keyword explanations
  ("Official Rulings"), lexical rules, grammar, AST shape, overflow ("riba")
  plan for all three stages, and the error catalogue.
- grammar.ebnf: written from the final design.
- src/lexer.py: the byte state machine. Includes Eastern Arabic digits
  (two-byte UTF-8), the i64 literal limit, columns counted in characters,
  and UTF-8 checks for unknown characters.
- src/parser.py: recursive descent with peek/eat, one method per grammar rule,
  and every syntax error message.
- src/ast_nodes.py, src/errors.py, compiler.py.
- tests/ok (19 programs + .ast), tests/err (38 programs + .expected), check.py.
- README.md and this file.
- vscode-halalscript/ (optional Task 3, not graded): the whole VS Code extension
  — TextMate grammar, language configuration, snippets, the TypeScript
  extension (live diagnostics through the bundled compiler, hover, completion,
  digit conversion, --ast viewer), grammar tests and integration tests that run
  inside a downloaded VS Code. The AI proposed the feature list; I chose to do
  both proposed levels and the .halal file extension. While checking the
  extension in my own VS Code, the AI found that it was switched off in
  Restricted Mode and fixed it, and it wrote the script that takes the
  screenshots in vscode-halalscript/images.

The AI ran every test program, read each --ast tree and each error position to
check them against the grammar by hand before saving them as the expected
output, and checked that check.py really reports a FAIL when an expected
file is wrong.


3. WHAT I DECIDED OR CHANGED (relative to the AI's proposals)
-------------------------------------------------------------

The language idea (HalalScript, bismillah = immutable, inshallah = mutable,
explanations and errors written in pseudo-dogmatic grandiloquent irony) is mine.
From the AI's first design draft I changed:

- compile-time constant keyword: the AI recommended `maktub`; I chose `wallahi`;
- declaration shape: chose `bismillah dirham x := 10` out of three options;
- blocks: the AI recommended only `yalla`/`khalas`; I asked for both
  `yalla`/`khalas` and `{ }`;
- the greeting `assalamu alaikum` is required (the AI offered it as an option);
- kept Eastern Arabic digits; included parentheses and `la` in stage 1;
- removed all emoji aliases, which the AI had proposed for every keyword;
- comments with `#`.

Taken as proposed: the other keywords (dirham, dinar, fatwa, halal/haram,
istikhara, qadarallah, yalla/khalas, ameen, la), their explanations, the error
messages, the AST dump format, and the test programs.
